Privacy Policy

Last updated: October 18, 2026

What this app is

Ranking Shorts is a personal automation used by a single channel owner to upload videos to their own YouTube channel through the YouTube Data API.

Data it accesses

  • Permission to upload videos to the owner's YouTube channel (the youtube.upload scope). It does not read, change or delete any other videos, comments, subscribers or account information.
  • No data from any other Google user is accessed, collected or stored.

How data is stored

The only stored credential is the channel owner's own sign-in token, kept encrypted in GitHub Actions secrets. No user data is sold, shared or transferred to third parties.

Google API Services

Ranking Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the project's GitHub profile.
